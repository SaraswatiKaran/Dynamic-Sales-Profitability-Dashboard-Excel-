# Dynamic-Sales-Profitability(Interactive Dashboard creation using MS Excel)
## Project Objectives
Analyzes multi-channel distribution and regional margin variations to optimize supply chains. Identifies top profit engines (CA, TX, NY) and diagnoses high-value product losses to drive data-backed risk mitigation.

## Questions (KPIs) 
- Compare the absolute shipment volumes across different logistical transport modes using a single chart.
- Which geographic territories are emerging as our top 5 corporate profit engines?
- Which specific high-value product lines are driving our worst revenue leaks (Bottom 3 least profitable)?
- List the top 10 localized metropolitan cities contributing the most to our net profit margins.
- What is the dynamic workload distribution between Delivery Truck, Express Air, and Regular Air networks?
- Which individual city hub acts as our primary micro-market profit engine?
- How do customer segments (Corporate, Home Office, Small Business) and product categories (Furniture, Office Supplies, Technology) cross-filter our overall profitability trends?

## Process
- Verify raw datasets for any missing values, transactional anomalies, and structural integrity.
- Made sure data is consistent and clean with respect to data types, formatting schemas, and geographic names using Power Query ETL.
- Established relationships in the Power Pivot Data Model (Data Modeling) using normalized lookup dimension tables.
- Created explicit Pivot Tables and Pivot Charts tailored to address each analytical business question asked.
- Merge all pivot tables and charts into a centralized dark-themed layout and apply slicers to make the final dashboard interactive and dynamic.
